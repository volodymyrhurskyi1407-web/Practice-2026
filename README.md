# Менеджер витрат (Expense Tracker)

Настільний застосунок для фіксації, перегляду та аналізу щоденних витрат користувача. Програма дозволяє зручно додавати нові витрати, видаляти помилкові записи, автоматично підраховує загальну суму та зберігає історію у локальний файл. Розроблено мовою Python з використанням фреймворку PyQt6 та сучасного декларативного інтерфейсу QML (QtQuick).

## Структура проєкту

* **`main.py`** — головний файл з бізнес-логікою програми (бекенд). Містить класи моделі даних (`ExpenseModel`) та управління логікою (`ExpenseManager`).
* **`main.qml`** — файл декларативного опису графічного інтерфейсу користувача (фронтенд).
* **`test_app.py`** — скрипт автоматизованого тестування функцій додавання, видалення та підрахунку загальної суми.
* **`expenses.json`** — файл бази даних, який створюється автоматично для локального збереження історії витрат.

## Формат JSON-файлу

Усі записи автоматично зберігаються та завантажуються з файлу `expenses.json`. Приклад структури масиву:

```json
[
    {
        "description": "Кава",
        "amount": 65.0,
        "category": "Продукти"
    },
    {
        "description": "Таксі",
        "amount": 150.0,
        "category": "Транспорт"
    }
]
```
## Як запустити

Переконайтеся, що на комп'ютері встановлено Python (під час встановлення обов'язково поставте галочку "Add Python to PATH").

Клонуйте цей репозиторій або завантажте файли проєкту в окрему папку.

Відкрийте термінал у папці з проєктом та створіть віртуальне середовище (рекомендовано):
python -m venv venv

Активуйте віртуальне середовище (для Windows):
.\venv\Scripts\activate

Встановіть необхідну бібліотеку PyQt6:
pip install PyQt6

Запустіть застосунок:
python main.py
